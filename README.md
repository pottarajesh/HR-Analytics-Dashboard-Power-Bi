HR Analytics Dashboard

Built an interactive HR Analytics Dashboard using Microsoft Power BI to analyze employee attrition patterns and workforce trends. This dashboard transforms raw HR data into actionable insights for better decision-making in employee retention and workforce planning.

Key Highlights
Designed KPI cards to track:
Total Employees
Attrition Count
Attrition Rate (%)
Average Age
Average Monthly Income
Average Years at Company
Developed visual insights for:
Attrition by Education Field
Attrition by Age Group
Attrition by Salary Slab
Attrition by Job Role
Attrition trends by Years at Company
Job Satisfaction analysis across roles
Applied data modeling and DAX measures for calculated metrics such as Attrition Rate and workforce averages.
Created an executive-friendly dashboard layout for quick HR performance monitoring.
Tools & Skills Used

Power BI • DAX • Data Cleaning • Data Visualization • Dashboard Design • HR Analytics

Project Outcome

This dashboard helps identify:
✔ High attrition segments
✔ Roles with low job satisfaction
✔ Salary bands linked to turnover
✔ Employee retention trends over time
